# 🔢 Counter Program

A simple and interactive Counter Program built using **HTML, CSS, and JavaScript**.

This project allows users to increase, decrease, and reset a counter value using interactive buttons.

## ✨ Features

- Increase the counter value (+).
- Decrease the counter value (-).
- Reset the counter to zero.
- Display the current counter value instantly.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Counter logic and interactivity.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Click the **+** button to increase the value.
5. Click the **-** button to decrease the value.
6. Click **Reset** to return the counter to zero.
